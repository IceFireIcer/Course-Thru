# 第三方开源项目许可证

本目录存放 Course-Thru（课速通）所依赖的第三方开源项目的许可证原文，用于合规地保留原作者署名。

| 项目 | 许可证 | 作者 / 版权 | 来源仓库 | 本项目使用的版本 | 许可证文件 |
|---|---|---|---|---|---|
| OCS 网课助手 | MIT | Copyright (c) 2022 enncy | https://github.com/ocsjs/ocsjs | 4.15.3 | `ocsjs-LICENSE.txt` |
| ScriptCat（脚本猫） | GPL v3 | 作者 CodFrm | https://github.com/scriptscat/scriptcat | v1.4.0 | `scriptcat-LICENSE.txt` |

- `ocsjs-LICENSE.txt`：OCS 网课助手 MIT 许可证原文（含作者 enncy 版权声明），来自其 GitHub 仓库 `4.15.3` 标签。
- `scriptcat-LICENSE.txt`：ScriptCat（脚本猫）GPL v3 许可证原文，来自其 GitHub 仓库 `v1.4.0` 标签。作者署名 CodFrm 见其仓库 `package.json` / `src/manifest.json`（GPL v3 标准文本本身不含作者名）。

> 注意：ScriptCat 采用 GPL v3（GNU GPL v3），而非 MIT。以浏览器扩展形式与 Course-Thru 一并分发时，请遵守 GPL v3 的适用条款。
